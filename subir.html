Bienvenido al editor

Pegá tu llave de GitHub para entrar. Se guarda solo en este dispositivo y no hay que volver a ponerla.

¿Cómo consigo una llave?
  1. Entrá a github.com → Fine-grained token con la cuenta dueña del sitio.
  2. Nombre: Anuncios – mi celular. Vencimiento: 1 año.
  3. Repository access → Only select repositories → CCTA_SITIO.
  4. Permissions → Contents → Read and write.
  5. Generate token, copiá la llave y pegala aquí.

    Sin configurar

    ¿Cómo consigo una llave gratis de Gemini?
    1. Entrá a aistudio.google.com/apikey con una cuenta de Google.
    2. Tocá Create API key y copiala.
    3. Pegala aquí y tocá Guardar. No pide tarjeta.
    ¿Cómo consigo una llave de Claude?
    1. Entrá a console.anthropic.com y creá una cuenta.
    2. Cargá saldo (unos pocos dólares alcanzan para cientos de afiches).
    3. Tocá Create Key, copiala y pegala aquí.

    Configuración del sitio

    Se guarda en el sitio y aplica para todos los visitantes.

    https://.goatcounter.com

    📈 Ver las estadísticas →

    ¿Cómo activo las estadísticas?
    1. Entrá a goatcounter.com/signup (gratis para iglesias y sitios sin fines de lucro).
    2. En Code poné un nombre corto, por ejemplo ccta, y completá el correo y la contraseña.
    3. Escribí ese mismo nombre aquí y tocá Guardar configuración.
    4. Las visitas del equipo (dispositivos con el editor) no se cuentan.
    ¿Cómo creo el calendario de reservaciones?
    1. En calendar.google.com (con la cuenta de la iglesia) tocá + junto a "Otros calendarios" → Crear calendario. Nombre: Reservaciones templos.
    2. En su configuración, en Permisos de acceso, marcá Hacer disponible públicamente → Ver solo libre/ocupado (así no se ven los nombres de quienes reservan).
    3. Más abajo, en Integrar el calendario, copiá el ID del calendario y pegalo aquí.
    4. Cada vez que confirmen una reservación, agréguenla en ese calendario y aparecerá como ocupado en la página de reservar.

    ¿Cómo funciona?

    1. En Nuevo anuncio elegí cómo empezar: con un afiche, contándole a la IA, con una plantilla o en blanco.
    2. Revisá los datos. Mirá a la derecha (o abajo en el celular) cómo va quedando.
    3. Tocá Publicar. En 1 o 2 minutos aparece en la página y se quita solo cuando pasa la fecha.
    4. En Publicados podés editar, duplicar o quitar anuncios.
    5. Tu trabajo se guarda solo en este dispositivo mientras escribís, por si cerrás la página.
