Acceso del equipo

Pegá tu llave de GitHub. Se guarda solo en este dispositivo; no hay que volver a ponerla.

¿Cómo consigo una llave?
  1. Entrá a github.com → Fine-grained token (con una cuenta que tenga acceso al repositorio del sitio).
  2. Nombre: Anuncios sitio. Vencimiento: el que quieran (ej. 1 año).
  3. Repository access → Only select repositories → escogé el repositorio del sitio.
  4. Permissions → Contents → Read and write.
  5. Tocá Generate token, copiá la llave y pegala aquí.
